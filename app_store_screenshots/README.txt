Snake Classic - App Store marketing screenshots (7.x)
====================================================

One folder per App Store Connect upload slot. Upload each folder to the
slot it is named after - never mix them; the sizes are not interchangeable.

  iphone-6.5/   1284 x 2778   App Store Connect > iPhone > 6.5" Display
  ipad-13/      2048 x 2732   App Store Connect > iPad   > 13" Display

10 frames each - App Store Connect's limit per slot. Upload in filename
order; the first three appear on the install sheet, so 01-home and
02-combo carry the most weight.

The two sets are not identical: iPhone has 03-modes, iPad has 05-go
(the versus countdown, which only the iPad capture caught).

Raw captures these were built from:

  ../ios_tablet_screenshots/   iPad Pro 13",      2064 x 2752
