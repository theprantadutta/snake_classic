# Localized Play Store listings

Draft listing copy for the 9 launch locales, ready to paste into Play Console
(Store presence → Main store listing → Manage translations).

- `title` — max 30 chars. "Snake Classic" stays untranslated (brand).
- `short` — max 80 chars.
- `full` — max 4000 chars.

These were drafted from the current feature set (July 2026: 8 game modes,
1v1 online multiplayer, tournaments, battle pass, 107 achievements, daily
challenges, skins/trails/themes, offline-first cloud sync, Pro). The English
file is the source — if the live Play listing differs, update `en.md` first
and keep translations in sync.

App Store (iOS) uses the same copy; its limits are title 30 / subtitle 30 /
description 4000, so `short` doubles as the subtitle basis (trim to 30 chars).
